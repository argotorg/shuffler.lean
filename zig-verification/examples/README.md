# Configuration template

`prove.json` is an inactive example. The endpoint and model are placeholders.
The prices are example numbers, not provider quotes. Set actual token prices
before a paid call. Set the key in the variable named by `apiKeyEnv`; do not put
it in the file. Match the reasoning-effort field to the provider API.

Copy and edit the file under ignored `local/`. Do not use campaign flags until
you have set a budget for that campaign and checked the model request. The
default proof build and CI do not read this example.
